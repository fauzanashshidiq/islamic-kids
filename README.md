## 📖 Tentang Proyek

**Islamic Kids** adalah sebuah aplikasi mobile yang dikembangkan menggunakan framework Flutter. Tujuan utama aplikasi ini adalah menyediakan sarana pembelajaran yang interaktif dan mudah diakses bagi anak-anak Muslim untuk mengenal dan menghafal bacaan penting sehari-hari.

Aplikasi ini mencakup kumpulan doa harian, niat shalat, dan bacaan shalat lengkap. Dengan antarmuka yang ramah anak, penggunaan animasi (Lottie), dan dukungan audio, diharapkan proses belajar menjadi lebih menarik dan tidak membosankan.

---

## ✨ Fitur Utama

Berikut adalah beberapa fitur unggulan yang tersedia dalam aplikasi Islamic Kids:

* **🤲 Kumpulan Doa Harian:** Berbagai doa untuk aktivitas sehari-hari (seperti doa sebelum makan, doa tidur, dll) yang disajikan dengan teks Arab, latin, dan terjemahannya.
* **🕌 Niat Shalat:** Panduan lengkap niat untuk shalat fardhu lima waktu.
* **📖 Bacaan Shalat:** Tuntunan bacaan shalat mulai dari takbiratul ihram hingga salam.
* **🔊 Dukungan Audio:** Fitur pemutar suara untuk membantu anak mendengar pelafalan yang benar (menggunakan `audioplayers`).
* **🎨 Animasi Menarik:** Penggunaan animasi Lottie untuk membuat tampilan lebih hidup dan disukai anak-anak.
* **📱 Tampilan Responsif:** Desain antarmuka yang menyesuaikan dengan berbagai ukuran layar perangkat mobile.

## 🛠️ Teknologi yang Digunakan

Aplikasi ini dibangun menggunakan teknologi dan paket (packages) berikut:

* **Framework:** [Flutter](https://flutter.dev/)
* **Bahasa Pemrograman:** [Dart](https://dart.dev/)
* **Paket Kunci:**
    * [`google_fonts`](https://pub.dev/packages/google_fonts) - Untuk tipografi yang menarik.
    * [`lottie`](https://pub.dev/packages/lottie) - Untuk merender animasi Adobe After Effects.
    * [`audioplayers`](https://pub.dev/packages/audioplayers) - Untuk memutar file audio bacaan doa.

## 🚀 Cara Menjalankan

Untuk menjalankan proyek ini di mesin lokal Anda, ikuti langkah-langkah berikut:

**Prasyarat:** Pastikan Anda telah menginstal Flutter SDK.

1.  **Clone Repositori**
    ```bash
    git clone [https://github.com/fauzanashshidiq/islamic-kids.git](https://github.com/fauzanashshidiq/islamic-kids.git)
    ```

2.  **Masuk ke Direktori Proyek**
    ```bash
    cd islamic-kids
    ```

3.  **Install Dependencies**
    Ambil semua paket yang diperlukan yang terdaftar di `pubspec.yaml`.
    ```bash
    flutter pub get
    ```

4.  **Jalankan Aplikasi**
    Pastikan emulator Anda berjalan atau perangkat fisik terhubung.
    ```bash
    flutter run
    ```
